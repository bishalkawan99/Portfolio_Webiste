Neon Wave Canvas — Demo

A highly-performant, fluid neon wave background built with the HTML5 Canvas 2D context. Multiple layered ribbon-like lines animate organically using a mix of sine and cosine functions. The canvas is fixed behind the UI and passes pointer events through so page elements remain interactive.
